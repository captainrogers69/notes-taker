004 · Weave bubble
  1. Tap the faded W on the right edge. Start typing, press Enter.
  2. Tap a circle to tick. Done items tuck into "Done".
  3. Tap ‹ or the list name to switch or create a list.
  4. Drag the bubble anywhere; it snaps to a side and half-hides when idle.
